# MNIST-Digit-Classification
# MNIST Handwritten Digit Classification

## Objective
Build a Neural Network using TensorFlow/Keras to classify handwritten digits (0-9).

## Dataset
MNIST Dataset

## Model Architecture
- Flatten Layer
- Dense(128, ReLU)
- Dense(10, Softmax)

## Results
Test Accuracy: 98%

## Experiment
Added Dropout Layer and compared results.
